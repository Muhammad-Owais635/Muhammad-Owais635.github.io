As Lectuere at, UET Lahore, I taught Python programming to **first-semester Environmental Engineering students**.

## 🐍 Programming Fundamentals with Python
- Designed and delivered course content tailored to students with no prior programming background.
- Covered essential topics: variables, data types, conditionals, loops, functions, and file handling.
- Focused on problem-solving techniques, logical thinking, and algorithmic design.
- Created real-world assignments to foster engagement and curiosity about coding.

This course served as the students' first encounter with computer science, and my goal was to make programming intuitive, accessible, and enjoyable.
