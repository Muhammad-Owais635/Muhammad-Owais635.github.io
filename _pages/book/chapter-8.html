Convolutional Neural Networks (CNNs)

8 min read 6 sections Draft

8.1Why Do We Need CNNs?

We need Convolutional Neural Networks (CNNs) because traditional neural networks are inefficient and ineffective for image data. Images have very high dimensionality, and using fully connected layers would require a huge number of parameters, leading to high computation cost and severe overfitting.

CNNs solve this by using local connectivity, shared weights, and pooling, which allow the network to automatically learn important visual features such as edges, shapes, and textures. They preserve spatial relationships in images, reduce the number of parameters, and achieve better accuracy, making them ideal for tasks like image classification, object detection, and face recognition.

8.2What Is a Convolution?

A convolution is a mathematical operation used in Convolutional Neural Networks (CNNs) to extract features from input data such as images. It works by sliding a small matrix called a filter (kernel) over the input and computing a weighted sum between the filter and the local region of the input.

In simple terms, convolution helps the network detect patterns like edges, corners, and textures by focusing on small parts of the image at a time, while preserving spatial relationships.

8.3Pooling

Pooling is applied after the convolution (and usually after activation) to reduce the size of the feature map while keeping important information. It is not applied to the raw image directly; instead, it works on the feature maps produced by convolution layers.

8.4CNN Architecture Overview

Below is a clear, step-by-step explanation of the CNN architecture shown in the image, explaining each layer, each value, and what they mean.

Example: handwritten digit image (like MNIST)

Input Layer

Input: (28 × 28 × 1)

  • 28 × 28 → height × width of the image

  • 1 → number of channels (grayscale image)

Convolution Layer 1

Conv 1: (5 × 5) kernel, valid padding

  • 5 × 5 → size of the filter (kernel)

  • Valid padding → no zero padding → output size reduces

  • n1 channels → number of filters used (e.g., 6, 16, etc.)

Output size shown:

(24 × 24 × n1)

Why 24 × 24?

28−5+1=24
Each filter extracts features like edges and curves.

Max Pooling Layer 1

Max Pooling: (2 × 2)

  • Reduces spatial size by taking maximum from each 2×2 block

  • Keeps important features, reduces computation

Output size:

(12 × 12 × n1)

Height and width are halved, channels stay the same.

Convolution Layer 2

Conv 2: (5 × 5) kernel, valid padding

  • Takes pooled feature maps as input

  • Learns more complex patterns (shapes, parts of digits)

Output size:

(8 × 8 × n2)

Why 8 × 8?

12−5+1=8

n2 = number of filters in second conv layer (more than n1 usually).

Max Pooling Layer 2

Max Pooling: (2 × 2)

Output size:

(4 × 4 × n2)

Further reduces spatial size while keeping strong features.

Flatten Layer

Flatten: (4 × 4 × n2 → 64 units)

  • Converts 3D feature maps into a 1D vector

Example:

4×4×4=64

Required before feeding into fully connected layers.

Fully Connected Layer (Hidden Layer)

Dense layer with ReLU activation

  • n units (e.g., 100 units)

  • Combines all extracted features

  • ReLU introduces non-linearity

Acts like a traditional neural network.

Fully Connected Output Layer

Output: 10 units (0–9)

  • Each neuron represents one class (digits 0 to 9)

  • Usually uses Softmax activation

Produces probabilities for each digit.

Overall Flow (Easy to Remember)

Image → Convolution → Pooling → Convolution → Pooling → Flatten → Dense → Output

8.5CNN Example in Keras

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

model = Sequential([
    Conv2D(32, (3, 3), activation='relu', input_shape=(32, 32, 3)),
    MaxPooling2D(2, 2),
    Conv2D(64, (3, 3), activation='relu'),
    MaxPooling2D(2, 2),
    Flatten(),
    Dense(128, activation='relu'),
    Dense(10, activation='softmax')
])

8.6CNN Architectures

  • LeNet-5 (1998) for Digit recognition (MNIST)

  • AlexNet (2012) for Large-scale image classification

  • VGGNet (2014) for Feature extraction andTransfer learning

  • Inception (GoogLeNet) for Multi-scale feature extraction

  • ResNet (2015) solved Vanishing gradients in deep CNNs

  • Enables very deep networks (100+ layers)

  • Stable gradients

  • State-of-the-art accuracy

Model Depth Key Idea Use Case
LeNet Shallow Simplicity Digits
AlexNet Medium ReLU + Dropout ImageNet
VGG Deep Uniform conv Features
Inception Wide Multi-scale Complex
ResNet Very deep Skip connections SOTA

Transfer Learning with CNNs: Reuse pre-trained weights from large datasets.

Example (Keras)

import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense
# Build CNN model
model = Sequential([
# Convolution layer
Conv2D(filters=32, kernel_size=(3,3), activation='relu', input_shape=(28, 28, 1)),
# Pooling layer
MaxPooling2D(pool_size=(2,2)),
# Flatten layer
Flatten(),
# Fully connected layer
Dense(128, activation='relu'),
# Output layer
Dense(10, activation='softmax')
])
# Compile model
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy']
)
# Model summary
model.summary()

Parameters

  • filters=32 → number of feature maps

  • kernel_size=(3,3) → filter size

  • activation='relu' → adds non-linearity

  • input_shape=(28,28,1) → grayscale image

  • pool_size=(2,2) → takes max value from 2×2 window

  • Flatten()→ Converts 2D feature maps into a 1D vector for dense layers.

  • 128 → number of neurons (Dense)

  • relu → non-linearity (Dense)

  • 10 → number of classes (Output layer)

  • softmax → converts scores to probabilities (Output layer)
