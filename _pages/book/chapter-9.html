Sequence Models and Recurrent Neural Networks

9.1Why Do We Need Sequence Models?

We need sequence models because many real-world problems involve ordered data, where the current output depends on previous inputs, not just the current one. Traditional models assume inputs are independent, so they fail to capture temporal or sequential relationships.

9.1.2Tokenization

Tokenization is the process of breaking text into smaller units called tokens so a model can process language.

Tokenization Level What it does Example (“banking”) Pros Cons
Word-level Splits text into full words 
["banking"]
 Simple, fast, keeps full meaning Large vocabulary, cannot handle unknown words
Subword-level Splits words into meaningful parts 
["bank", "ing"]
 Handles unknown words, smaller vocabulary, widely used Slightly complex, tokens less readable
Character-level Splits text into characters 
["b","a","n","k","i","n","g"]
 No unknown words, very small vocabulary Very long sequences, slow, harder to learn meaning

9.1.3What is Word2Vec?

Word2Vec is a technique that converts words into dense numerical vectors such that words with similar meanings have similar vectors. It learns word representations by predicting context words from a target word or vice versa. It captures semantic relationships like:

king − man + woman ≈ queen

          9.1.9Skip-Gram

          Predicts surrounding context words from a center (target) word.

          Example sentence: “The bank grows fast”

          Target word = bank

          Input (target): bank
Output (context): the, grows

          1. Input target word
            Target word → one-hot vector.

          2. Embedding lookup
            One-hot × embedding matrix → target embedding.

          3. Predict context words
            For each context word:

          y​=softmax(Wvtarget​)

          1. Training
            Error for each predicted context word updates the embeddings.

          Type Full Name What it predicts How it works (simple) Pros Cons

          Skip-Gram Skip-Gram Model Context words Uses a center word to predict surrounding words Good for rare words, better embeddings Slower than CBOW

          9.2Sequence Model

          A sequence model processes input one step at a time, maintaining a memory (state). Sequence models (like RNNs, LSTMs, GRUs) maintain a memory of past information, allowing them to understand patterns over time. This makes them essential for tasks such as speech recognition, language translation, text generation, time-series forecasting, and video analysis, where context and order matter

          Example

          "I love deep learning."

          Meaning depends on word order.

          9.3What Is a Recurrent Neural Network (RNN)?

          A Recurrent Neural Network (RNN) is a type of neural network designed to process sequential data by using feedback connections. Unlike feedforward networks, an RNN has a memory that allows it to retain information from previous time steps and use it to influence the current output.

          At each time step, the RNN takes the current input and the previous hidden state to produce a new hidden state. This makes RNNs suitable for tasks where order and context matter, such as language modeling, speech recognition, and time-series prediction.

          9.4Feedforward NN vs RNN

          Feedforward Neural Network (FNN)

          • Information flows only in one direction (input → hidden → output).

          • No memory of past inputs.

          • Each input is processed independently.

          Example: Image classification: One image → one output (no sequence).

          Recurrent Neural Network (RNN)

          • Has a loop (feedback connection).

          • Maintains a hidden state that carries information from the past.

          • Can remember previous inputs.

          Example: Sentence, time series, speec: Current word depends on previous words.

          9.6Vanishing Gradient

          The vanishing gradient problem occurs when training deep neural networks (especially RNNs) where gradients become very small as they are backpropagated through many layers or time steps. When gradients approach zero, earlier layers (or earlier time steps) learn extremely slowly or stop learning completely.

          Why It Happens

          • Repeated multiplication of gradients less than 1

          • Activation functions like sigmoid or tanh squash values into small ranges

          • In RNNs, the same weights are reused across many time steps

          Mathematically:

          ∂W∂L​=∏(small values)→0
          Simple Example :Consider the sentence:

          “I grew up in France and I speak French”

          An RNN should remember “France” to predict “French”, but due to vanishing gradients, the influence of early words fades, and the model forgets long-term information.

          9.7Exploding Gradient

          The exploding gradient problem occurs when gradients become very large during backpropagation in deep neural networks or RNNs. As gradients grow exponentially, parameter updates become unstable, causing the model to diverge and the loss to become NaN or infinity.

          Why It Happens

          • Repeated multiplication of large values (>1) during backpropagation

          • Poor weight initialization

          • Long sequences in RNNs

          Mathematically:

          ∂W∂L​=∏(large values)→∞

          Simple Example

          For a long sentence or time series, the gradient grows larger at each time step, causing the model weights to update too aggressively and overshoot the minimum. So Loss suddenly becomes very large, training becomes unstable and model fails to converge

          9.8Applications of RNNs

          Model Type Input Output Description When to Use / Examples
          Many-to-One Sequence Single output Entire input sequence mapped to one output • Sentiment analysis (review → positive/negative) • Spam detection • Document classification
          One-to-Many Single input Sequence One input generates a sequence of outputs • Image captioning (image → sentence) • Music generation • Text generation from a seed word
          Many-to-Many (Same length) Sequence Sequence Output at every time step • Part-of-speech tagging • Named entity recognition • Time-series forecasting
          Many-to-Many (Different length) Sequence Sequence Input and output sequence lengths differ • Machine translation (English → French) • Speech-to-text • Text summarization

          9.9Simple RNN in Keras

          import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense, Embedding
# Build RNN model
model = Sequential([
# Embedding layer (text → vectors)
Embedding(input_dim=5000, output_dim=64, input_length=20),
# Simple RNN layer
SimpleRNN(units=50, activation='tanh'),
# Output layer
Dense(1, activation='sigmoid')
])
# Compile model
model.compile(
optimizer='adam', loss='binary_crossentropy', metrics=['accuracy']
)
model.summary()

          Parameters

          • input_dim=5000 → vocabulary size

          • output_dim=64 → embedding dimension

          • input_length=20 → sequence length

          • units=50 → hidden state size

          • tanh → activation function
