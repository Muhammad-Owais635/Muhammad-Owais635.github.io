Regularization

4 min read 1 sections Draft

7.1What Is Regularization?

Regularization is a technique used to prevent overfitting by adding a penalty term to the loss function that discourages overly complex models. It works by limiting the size of model parameters (weights), which helps the model focus on the most important patterns in the data instead of memorizing noise.

Common types of regularization include L1 regularization (Lasso), which can drive some weights to zero and perform feature selection, and L2 regularization (Ridge), which reduces large weights smoothly. By controlling model complexity, regularization improves the model’s ability to generalize to unseen data.

7.1.1Ridge Regularization (L2 Regularization)

It is a technique used to reduce overfitting by adding a penalty based on the square of the weights to the loss function. This penalty discourages the model from assigning very large values to weights, helping it learn smoother and more general patterns instead of memorizing the training data.

Lossridge​=Loss+λ∑w2

Here, λis the regularization parameter that controls the strength of the penalty. A larger λforces weights to be smaller, increasing bias but reducing variance, while a smaller λallows the model more flexibility. Ridge regularization improves generalization but does not set weights exactly to zero.

7.1.2L1 Regularization (Lasso)

It is a technique used to reduce overfitting by adding a penalty equal to the absolute values of the weights to the loss function. This encourages the model to shrink less important weights toward zero, and in many cases, it sets them exactly to zero, effectively performing feature selection.

Losslasso​=Loss+λ∑∣w∣

Here, λis the regularization parameter that controls the strength of the penalty. A larger λincreases sparsity by forcing more weights to zero (higher bias, lower variance), while a smaller λallows the model to remain more flexible. L1 regularization is especially useful when many input features are irrelevant.

7.1.3Elastic Net

Elastic Net Regularization is a technique that combines the strengths of L1 (Lasso) and L2 (Ridge) regularization to reduce overfitting. It adds both the absolute value and the squared value of the weights as penalties, helping the model handle correlated features while also performing feature selection.

LossElastic Net​=Loss+λ1​∑∣w∣+λ2​∑w2

Here, λ1​controls the L1 penalty (sparsity and feature selection) and λ2​controls the L2 penalty (weight shrinkage and stability). Elastic Net is especially useful when there are many features and strong correlations among them, where Lasso alone may fail.

7.1.4Dropout Regularization

Dropout is a regularization technique used in neural networks to reduce overfitting. During training, it randomly deactivates (drops) a fraction of neurons in a layer for each iteration. This prevents the network from becoming too dependent on specific neurons and forces it to learn more robust and generalized features.

The dropout rate (for example, 0.5) determines the percentage of neurons that are turned off during training. Dropout is applied only during training, not during testing or inference. By reducing co-adaptation among neurons, dropout improves generalization and helps the model perform better on unseen data.

7.1.5Early Stopping

Early stopping is a regularization technique used to prevent overfitting during model training. While training a model, both training loss and validation loss are monitored. Initially, both losses decrease, but after some point, the validation loss may start increasing even though training loss continues to decrease. Early stopping stops the training process at this point to avoid learning noise from the training data.

In simple terms, early stopping helps the model stop learning at the right time, improving generalization and reducing unnecessary training.

7.1.6Data-Based Regularization

Data-based regularization refers to techniques that reduce overfitting by modifying or improving the training data itself, rather than changing the model or loss function. The main idea is to expose the model to more diverse and representative data so it learns general patterns instead of memorizing specific examples.

Common examples include data augmentation (such as rotating, flipping, or adding noise to images), adding noise to inputs, and shuffling data. These methods effectively increase the size and diversity of the dataset, helping the model generalize better without increasing model complexity.
