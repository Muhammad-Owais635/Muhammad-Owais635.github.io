Gated Recurrent Units (GRU)

5 min read 4 sections Draft

LSTM has too many gates , Slower training andHigh memory usage

11.1GRU

A GRU (Gated Recurrent Unit) is a type of Recurrent Neural Network (RNN) designed to handle vanishing gradient problems like LSTM, but with a simpler structure and fewer parameters.

Unlike LSTM, a GRU has two gates instead of three:

  • Update gate (zₜ) – decides how much past information to keep

  • Reset gate (rₜ) – decides how much past information to forget

There is no separate cell state in GRU; the hidden state carries all information.

Why use GRU?

  • Faster training than LSTM

  • Requires less memory

  • Works well on smaller datasets

  • Comparable performance to LSTM in many tasks

Used in, NLP tasks (text classification, translation), Speech recognition and Time-series prediction

11.2Core Idea of GRU

Combine forget + input gates into one update gate

Inputs

  • xₜ → input at current time step

  • hₜ₋₁ → hidden state from previous time step

These two are combined and fed into the gates.

Reset Gate (rₜ)

In the diagram, this is the σ (sigmoid) block on the left.

Purpose:
Controls how much past information to forget.

rt​=σ(Wr​xt​+Wrh​ht−1​)

  • If rₜ ≈ 0 → forget past

  • If rₜ ≈ 1 → keep past

The ⊙ (element-wise multiplication) shows the reset gate filtering the previous hidden state.

Update Gate (zₜ)

Another σ (sigmoid) block in the diagram. Decides how much old memory vs new memory to keep.

zt​=σ(Wz​xt​+Wzh​ht−1​)

Candidate Hidden State (h̃ₜ)

This is the tanh block in the diagram.

ht​=tanh(Wh​xt​+whh​(rt​⊙ht−1​))

  • Uses the reset gate output

  • Generates new candidate memory

Final Hidden State (hₜ)

Shown using:

  • 1 − zₜ

  • ⊙ multiplications

  • + (addition)

ht​=zt​⊙ht−1​+(1− zt​)⊙ht​

This combines:

  • Old memory (hₜ₋₁)

  • New candidate (h̃ₜ)

11.3Example Sentence: “I love AI”

Sentence (sequence of words):

["i", "love", "ai"]

Word xₜ
i 0.5
love 0.8
ai 1.0

Initial hidden state:

h₀ = 0

All Weights (chosen for simplicity are equal to 1):

STEP 1: Word = "i"

Reset Gate (r₁)

r1​=σ(Wr​xt​+Wrh​ht−1​)= σ(0.5+0)=0.62

Update Gate (z₁)

z1​=σ(Wz​xt​+Wzh​ht−1​)=σ(0.5+0)=σ(0.5)z1​≈0.62

Candidate Hidden State (h̃₁)

h1​=tanh(Wh​xt​+whh​(rt​⊙ht−1​))=tanh(0.5+(0.62×0))h1​=tanh(0.5)≈0.46

Final Hidden State (h₁)

h1​=zt​⊙ht−1​+(1− zt​)⊙ht​= (0.62)×0+(1−0.62)×0.46h1​≈0.29
Memory after "i" = 0.29

STEP 2: Word = "love"

Reset Gate (r₂)

r2​=σ(1.09)≈0.75
🔹 Update Gate (z₂)

z2​=σ(0.8+0.29)=σ(1.09)z2​≈0.75
🔹 Candidate Hidden State (h̃₂)

h2​=tanh(0.8+(0.75×0.29))h2​=tanh(1.02)≈0.77
🔹 Final Hidden State (h₂)

h2​=(1−0.75)×0.29+0.75×0.77h2​≈0.65

Memory after "love" = 0.65 Strong positive sentiment is remembered

STEP 3: Word = "ai"

Reset Gate (r₃)

r3​=σ(1.65)≈0.84
🔹 Update Gate (z₃)

z3​=σ(1.0+0.65)=σ(1.65)z3​≈0.84

Candidate Hidden State (h̃₃)

h3​=tanh(1.0+(0.84×0.65))h3​=tanh(1.55)≈0.91

Final Hidden State (h₃)

h3​=(1−0.84)×0.65+0.84×0.91h3​≈0.87
Final memory = 0.87, it does NOT mean only “ai” or only “love”.

It means: A weighted mixture of all previous words “i”, “love”, and “ai” controlled by the update gate at each step.

11.4GRU in Keras (Example)

import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import GRU, Dense, Embedding
model = Sequential([
Embedding(input_dim=5000, output_dim=64, input_length=20),
GRU(units=50),
Dense(1, activation='sigmoid')
])
model.compile(
optimizer='adam', loss='binary_crossentropy', metrics=['accuracy']
)
model.summary()

  • input_dim = 5000 → vocabulary size

  • output_dim = 64 → embedding dimension

  • input_length = 20 → number of words per input

  • units = 50 → number of GRU neurons

  • 1 neuron → binary output

  • sigmoid → probability between 0 and 1
