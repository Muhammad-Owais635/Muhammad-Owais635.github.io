Chapter 12

The Transformer Architecture

27 min read 13 sections Draft

The Transformer is an attention-based neural network architecture composed of stacked encoder and decoder layers that model global dependencies in sequences through self-attention and feed-forward networks, eliminating the need for recurrent or convolutional structures.

12.1Why Attention Was Needed

Limitations of RNN/LSTM/GRU are that they process tokens sequentially, Forget long-range dependencies and Slow training. Attention allows the model to focus on relevant parts of the input directly.

12.2Intuition: Human Attention

“He saw the man with a telescope.”

This sentence is ambiguous, and attention helps resolve it.

Two possible meanings: Meaning 1 (most common)

He used the telescope to see the man

Attention focuses on “he” ↔︎ “telescope”

Meaning 2

He saw a man who had a telescope

Attention focuses on “man” ↔︎ “telescope”

12.3What Is Attention?

Self-attention is a mechanism that lets each word look at all other words in the same sentence and decide which ones matter most to its meaning.

Each word asks: “Which other words should I pay attention to?”

Traditional models read words one by one. Transformers read all words at once, and self-attention tells them how words relate to each other.

12.4Example: “Money Bank Grows, River Bank Flows”

We are taking Money, Flow, and Bank words only for understanding.

Vector Meaning
Query (Q) What this word is looking for
Key (K) What each word offers
Value (V) The information to pass along

Money = [1, 0]

In a Transformer, Query (Q), Key (K), and Value (V) vectors are computed by applying three different learned linear transformations from the same data to the input word embeddings.

Money

V_money = [1, 1]

S11 = Q_money ↔︎ K_money = [1,0] · [1,1] = 1

S32 = Q_flow ↔︎ K_bank = [1, 1] · [0,1] = 1
S33 = Q_flow ↔︎ K_flow = [1, 1] · [1,2] = 3

softmax(si​)=∑j​esj​esi​​

 w11 = 2.718 / 6.436 ≈ 0.422

The output vector y_bank is context-aware and changes depending on the surrounding words.
When the word bank appears with money, its output vector becomes more aware of financial meaning.
When the same word bank appears with river or flow, its output vector becomes more aware of the geographical meaning.

Thus, the same word bank produces different context-aware output vectors in different sentences because self-attention incorporates information from related words.

12.5What is Multi-Head Attention?

Multi-Head Attention means running self-attention multiple times in parallel, each time with different learned projections, and then combining the results.

Instead of using one way to look at relationships between words, the model uses multiple perspectives (heads).

Why Multi-Head Attention is needed

A single attention head can focus on only one type of relationship.

Multi-head attention allows the model to learn:

  • syntactic relations (subject–verb)

  • semantic relations (meaning)

  • positional relations

  • long-range dependencies at the same time

  • Each word is represented as an embedding vector:
    X = [x_money, x_bank]

  • For each attention head h, separate projection matrices are learned:
    WQₕ, WKₕ, WVₕ

  • Queries, Keys, and Values are computed for each head:
    Qₕ = XWQₕ , Kₕ = XWKₕ , Vₕ = XWVₕ

  • Each head attends to the same input words but learns different relationships.

  • Each head produces an attention output:
    head₁, head₂, …, headₕ

  • Outputs from all heads are concatenated:
    Concat(head₁, head₂, …, headₕ)

  • The concatenated vector is linearly projected using WO.

  • Final output is obtained as:
    Y = Concat(head₁, …, headₕ) · WO

12.6Positional Encoding

Transformers process all words in parallel, so they do NOT know word order by default.

Example (without position):

  • “dog bites man”

  • “man bites dog”

Both look identical to a Transformer unless we add position information. Positional encoding tells the model where each word is in the sentence.

Positional encoding is a vector added to each word embedding to encode its position in the sequence. With positional encoding attention can learn order, learn distance and can distinguish subject vs object.

Final input to the Transformer = Word embedding + Positional encoding

How it works (simple view)

For each position pos in the sentence, we create a position vector:

x_input = word_embedding + position_embedding

So: Same word at different positions → different final vectors

Example (easy numbers)

Sentence: “Money bank grows.”

Word embeddings (simplified):

Money = [1.0, 0.5]
Bank = [0.8, 0.3]
Grows = [0.6, 0.9]

Positional encodings:

Position 0 = [0.0, 1.0]
Position 1 = [0.5, 0.5]
Position 2 = [1.0, 0.0]

Final inputs:

Money → [1.0, 0.5] + [0.0, 1.0] = [1.0, 1.5]
Bank → [0.8, 0.3] + [0.5, 0.5] = [1.3, 0.8]
Grows → [0.6, 0.9] + [1.0, 0.0] = [1.6, 0.9]

12.6.1Sinusoidal positional encoding (used in original Transformer)

Instead of learning position vectors, the original Transformer uses fixed sine and cosine functions:

PE(pos,2i)=sin(100002i/dpos​)PE(pos,2i+1)=cos(100002i/dpos​)

It is unique for each position, allows the model to generalize to longer sequences, and encodes the relative distance between words

Nearby positions → similar encodings

Type Description
Learned Position vectors learned during training
Sinusoidal Fixed mathematical functions

12.7What is normalization in Transformers?

Normalization (Layer Normalization) is used to stabilize and speed up training by keeping values in a reasonable range. It makes the model easier to train and prevents exploding or vanishing values.

Input
↓
Self-Attention
↓
Add (Residual Connection)
↓
Layer Normalization

and again after the Feed-Forward Network.

12.7.1What is Layer Normalization?

Layer Normalization normalizes each token’s feature vector independently.

For a vector x:

LayerNorm(x)=σx−μ​⋅γ+β

Where:

  • μ = mean of the vector

  • σ = standard deviation

  • γ, β = learnable parameters

Simple example

Input vector:

x = [2, 4, 6]

Mean:

μ = (2 + 4 + 6)/3 = 4

Std:

σ = sqrt(((2−4)² + (4−4)² + (6−4)²)/3) ≈ 1.63

Normalized:

[(2−4)/1.63, (4−4)/1.63, (6−4)/1.63]
≈ [−1.23, 0, 1.23]

12.7.2Why Transformers use LayerNorm (not BatchNorm)

BatchNorm LayerNorm
Depends on batch size Works with any batch size
Not good for sequences Ideal for NLP
Normalizes across batch Normalizes across features

Normalization helps self-attention by keeping Q·K values stable, prevents very large attention scores, improves gradient flow and makes deep Transformers trainable

12.8Transformer Encoder

The Transformer encoder transforms input tokens into deep, context-aware representations using self-attention, positional encoding, feed-forward layers, and normalization.

Example sentence “Money bank grows”

Inputs (Tokens)

[Money, Bank, Grows]

12.8.1Input Embedding

Converts words into dense numerical vectors that capture basic meaning.

Each word → embedding vector:

X=​xmoney​xbank​xgrows​​​
These embeddings are learned from training data.

12.8.2Positional Encoding

Adds word-order information so the model knows the position of each word.

X′=X+PE
Now each vector contains:

  • word meaning

  • position in the sentence

12.8.3Multi-Head Self-Attention

Allows each word to attend to all other words and gather relevant context.

12.8.4Query, Key, Value creation

Projects are embedded into three spaces to decide what to look for, what to match, and what information to pass.

Q=X′WQ​

K=X′WK​

V=X′WV​

12.8.5Scaled Dot-Product Attention (Self attention)

Computes how strongly each word should attend to other words.

Attention(Q,K,V)=softmax(dk​​QKT​)V
This produces attention-weighted representations.

12.8.6Multi-Head Attention

Runs self-attention multiple times in parallel to capture different relationships.

MultiHead=Concat(head1​,…,headh​)WO​

Each head focuses on a different aspect of meaning or syntax.

12.8.7Add & Layer Normalization (after Attention)

Preserves original information and stabilizes training. It add results from multihead attention and X calculated after positional encoding and then apply layer normalization on it.

Z1​=LayerNorm(X′+MultiHead(X′))

12.8.8Feed-Forward Network (FFN)

The Feed-Forward Network in a Transformer encoder is a position-wise neural network that applies nonlinear transformations to each token independently, refining the contextual information produced by self-attention. Applies a non-linear transformation to each word independently to enrich representations.

FFN(x)=max(0,xW1​+b1​)W2​+b2​

12.8.9Add & Layer Normalization (after FFN)

Combines transformed features with previous information and normalizes them.

Z2​=LayerNorm(Z1​+FFN(Z1​))

12.8.10Stacking Encoder Layers

Repeats the encoder block multiple times to build deep contextual understanding.

EncoderOutput=EncoderN​(…Encoder1​(X′))

12.9Masked attention

In decoding, the model generates tokens one by one.

Example target sentence: "I love transformers"

When predicting:

  • "love" → model should not see "transformers"

  • "transformers" → model should see "I" and "love"

Without masking, the model could “cheat” by looking at future words during training.So masked attention enforces: A token can only attend to itself and previous tokens.

12.10Transformer Decoder

A Transformer decoder is the part of a Transformer model that generates the output sequence step by step, using both previously generated output tokens and the encoded representation of the input sequence.

In simple words:

The Transformer decoder predicts the next word by looking at what it has already generated and by selectively focusing on the most relevant parts of the input sentence.

What the Transformer decoder does

At each time step, the decoder:

  • Remembers past outputs (but not future ones)

  • Consults the input sentence via the encoder

  • Transforms this information to predict the next token

  • This makes the decoder autoregressive (outputs are generated one after another).

Each decoder layer consists of three operations, applied in order:

  1. Masked self-attention
    Allows each output token to attend only to earlier output tokens, ensuring the model does not see future words.

  2. Cross-attention (encoder–decoder attention)
    Allows the decoder to attend to the encoder’s output, so generation is conditioned on the input sequence.

  3. Feed-forward network (FFN)
    Applies nonlinear transformations to refine the token representations.

Each operation uses residual connections and layer normalization for stable training.

12.10.1 Example: I love transformers

Assume

  • Vocabulary size = V

  • Embedding dimension = d_model = 4 (small for understanding)

  • Sequence length = 3

STEP 1: Create embeddings (your step)

Tokens

["I", "love", "transformers"]

Embedding lookup

Each word is mapped to a dense vector using an embedding matrix E∈RV×dmodel​.

X=[x1​,x2​,x3​]

Example embeddings (illustrative):

x₁ = embedding("I") = [0.10, 0.20, 0.30, 0.40]
x₂ = embedding("love") = [0.50, 0.60, 0.10, 0.20]
x₃ = embedding("transformers") = [0.90, 0.10, 0.40, 0.70]

Each xᵢ

  • Encodes semantic meaning of the word

  • Has no position information

  • Does not yet know about other words

So far:“These vectors only know what the word is, not where it is or what surrounds it.”

STEP 2: Add positional encoding

Transformers need position information.

Xpos​=X+P

Assume positional encodings:

p₁ = [0.01, 0.00, 0.01, 0.00]
p₂ = [0.02, 0.01, 0.00, 0.01]
p₃ = [0.03, 0.02, 0.01, 0.00]

After addition

x₁' = [0.11, 0.20, 0.31, 0.40]
x₂' = [0.52, 0.61, 0.10, 0.21]
x₃' = [0.93, 0.12, 0.41, 0.70]

Meaning now each vector now knows:

  • Word meaning

  • Its position in the sequence

STEP 3: Create Query, Key, Value vectors (Masked Self-Attention)

We apply three linear layers:

Q=Xpos​WQ​,K=Xpos​WK​,V=Xpos​WV​

Each token produces three vectors.

Example for token "love"

q₂ = [0.6, 0.2]
k₂ = [0.4, 0.9]
v₂ = [0.7, 0.1]

Meaning of Q, K, V

  • Query (Q) → what this token is looking for

  • Key (K) → what this token offers

  • Value (V) → information to pass if attended to

STEP 4: Compute attention scores

This produces a score matrix:

I love transformers
I s11 s12 s13
love s21 s22 s23
trans s31 s32 s33

STEP 5: Apply causal (look-ahead) mask

Decoder must not see future tokens.

I love transformers
I 0 -∞ -∞
love 0 0 -∞
trans 0 0 0

Meaning:

  • Token 1 can only attend to token 1

  • Token 2 → tokens 1 & 2

  • Token 3 → tokens 1, 2 & 3

Apply mask: masked_scores=scores+mask. So Masked values become −∞.

STEP 6: Softmax → attention weights

αi,j​=softmax(masked scores)
Example for "love":

α₂ = [0.7, 0.3, 0.0]

Meaning:

  • 70% attention to "I"

  • 30% to itself

  • 0% to "transformers"

So future tokens get zero attention weight.

STEP 7: Weighted sum of Value vectors

zi​=j∑​αi,j​vj​
For "love":

z₂ = 0.7·v₁ + 0.3·v₂

What z₂ represents

  • A context-aware representation

  • Knows:

    • Meaning of "love"

    • Relation to "I"

    • Cannot see "transformers"

STEP 8: Add & Layer Normalization

h1​=LayerNorm(Xpos​+Z)

Meaning: Keeps original token info, Adds contextual info and Stabilizes training

STEP 9: Cross-Attention (decoder ↔︎ encoder)

Now the decoder looks at the encoder output.

Inputs

  • Query → decoder hidden states

  • Key, Value → encoder outputs

Same attention formula, but the Decoder asks questions and the encoder answers. Cross attention allows the decoder to attend to encoder outputs by using decoder states as queries and encoder states as keys and values, enabling the model to align and condition output tokens on the input sequence.

Output vectors now encode

  • Past output context

  • Input sentence relevance

STEP 10: Feed-Forward Network (FFN)

For each token independently:

FFN(x)=GELU(xW1​+b1​)W2​+b2​

It Learns complex nonlinear transformations and refines representation

STEP 11: Final linear layer + softmax

P(yt+1​)=softmax(hWo​)
Output:

P("transformers") = 0.72
P("you") = 0.10
P("it") = 0.05
...

Training

  • Encoder and decoder run in parallel

  • Cross-attention links them

Inference

  • Encoder runs once

  • Decoder repeatedly queries encoder outputs

Code to train Transformer from scratch

import tensorflow as tf
from tensorflow.keras import layers
import numpy as np
# -------- Scaled Dot-Product Attention --------
def scaled_dot_product_attention(Q, K, V):
dk = tf.cast(tf.shape(K)[-1], tf.float32)
scores = tf.matmul(Q, K, transpose_b=True) / tf.math.sqrt(dk)
weights = tf.nn.softmax(scores, axis=-1)
output = tf.matmul(weights, V)
return output
# -------- Multi-Head Attention --------
class MultiHeadAttention(layers.Layer):
def __init__(self, d_model, num_heads):
super().__init__()
self.num_heads = num_heads
self.d_model = d_model
self.depth = d_model // num_heads
self.WQ = layers.Dense(d_model)
self.WK = layers.Dense(d_model)
self.WV = layers.Dense(d_model)
self.WO = layers.Dense(d_model)
def split_heads(self, x, batch_size):
x = tf.reshape(x, (batch_size, -1, self.num_heads, self.depth))
return tf.transpose(x, perm=[0, 2, 1, 3])
def call(self, x):
batch_size = tf.shape(x)[0]
Q = self.split_heads(self.WQ(x), batch_size)
K = self.split_heads(self.WK(x), batch_size)
V = self.split_heads(self.WV(x), batch_size)
attention = scaled_dot_product_attention(Q, K, V)
attention = tf.transpose(attention, perm=[0, 2, 1, 3])
concat = tf.reshape(attention, (batch_size, -1, self.d_model))
return self.WO(concat)
# -------- Feed Forward Network --------
def feed_forward(d_model, dff):
return tf.keras.Sequential([
layers.Dense(dff, activation="relu"),
layers.Dense(d_model)
])
# -------- Encoder Layer --------
class EncoderLayer(layers.Layer):
def __init__(self, d_model, num_heads, dff):
super().__init__()
self.mha = MultiHeadAttention(d_model, num_heads)
self.ffn = feed_forward(d_model, dff)
self.norm1 = layers.LayerNormalization()
self.norm2 = layers.LayerNormalization()
def call(self, x):
attn = self.mha(x)
x = self.norm1(x + attn)
ffn = self.ffn(x)
return self.norm2(x + ffn)
# -------- Transformer Model --------
class Transformer(tf.keras.Model):
def __init__(self, vocab_size, d_model, num_heads, dff):
super().__init__()
self.embedding = layers.Embedding(vocab_size, d_model)
self.encoder = EncoderLayer(d_model, num_heads, dff)
self.pool = layers.GlobalAveragePooling1D()
self.fc = layers.Dense(1, activation="sigmoid")
def call(self, x):
x = self.embedding(x)
x = self.encoder(x)
x = self.pool(x)
return self.fc(x)
# -------- Create Model --------
model = Transformer(
vocab_size=5000,
d_model=64,
num_heads=4,
dff=128
)
model.compile(
optimizer="adam",
loss="binary_crossentropy",
metrics=["accuracy"]
)
# -------- Dummy Training Data --------
X_train = np.random.randint(0, 5000, (1000, 20))
y_train = np.random.randint(0, 2, (1000, 1))
# -------- Train --------
model.fit(X_train, y_train, epochs=3, batch_size=32)
# -------- Save Model --------
model.save("transformer_model")
print("Model saved successfully!")
# =========================
# LOAD MODEL LATER
# =========================
loaded_model = tf.keras.models.load_model(
"transformer_model",
custom_objects={
"Transformer": Transformer,
"EncoderLayer": EncoderLayer,
"MultiHeadAttention": MultiHeadAttention
}
)
print("Model loaded successfully!")
# -------- Predict --------
test_sentence = np.array([[12, 45, 89, 203, 0, 0, 0, 0, 0, 0]])
prediction = loaded_model.predict(test_sentence)
print("Prediction:", prediction)

12.11Pre-training

Pretraining is the first training phase where a model learns general knowledge and patterns from a very large dataset, usually without a specific task in mind.

OR

Pretraining teaches the model the basics of language—grammar, meaning, and structure—by exposing it to massive amounts of text.

Typical pretraining objectives

  • Next-token prediction (GPT)

  • Masked language modeling (BERT)

12.12Fine-tuning

Fine-tuning is the second training phase where a pretrained model is adapted to a specific task using a smaller, labeled dataset. Fine-tuning teaches the model how to apply what it already knows to a particular job.

How it works

  • Starts from a pretrained model

  • Trained on task-specific data

  • Updates:

    • All parameters (full fine-tuning), or

    • A small subset (parameter-efficient tuning)

Example Adapting a pretrained language model to Sentiment analysis, Question answering or Translation.

12.12.1BERT architecture

BERT (Bidirectional Encoder Representations from Transformers) is a Transformer encoder-based model designed to understand language by looking at context from both left and right simultaneously. Used for:

  • Text classification

  • Question answering

  • Named entity recognition

  • Sentence similarity

BERT → Understand text → Encoder only→ Sees future tokens during training → Not autoregressive

MLM (Masked Language Modeling)

MLM is a training objective where some words in a sentence are masked, and the model learns to predict the missing words using surrounding context.

NSP (Next Sentence Prediction)

NSP is a training task where the model learns to predict whether one sentence logically follows another sentence in the original text.

Model.

  • L Layers.

  • H Hidden layer size aka dimension of embeddings.

  • A Attention heads operating in parallel

Input representation

BERT input embedding = Token Embedding + Segment Embedding + Positional Embedding

Example input:

[CLS] I love transformers [SEP]

[CLS] is a special token added at the very beginning of the input sequence. It does not represent a real word. Its purpose is to store information about the entire sentence. [CLS] gets its own embedding vector. It participates in self-attention like every other token. It attends to all tokens and all tokens attend to it

[SEP] is used at the end of every sentence sequence BERT has no recurrence, so it needs explicit sentence boundaries. It tells the model where one sentence ends, and another begins and helps attention understand sentence structure.

  • [CLS] vector → used as output representation

  • [SEP] vector → used as a boundary marker, usually not used directly

Encoder layers (core of BERT)

BERT consists of stacked Transformer encoder layers.

Each encoder layer contains:

  • Bidirectional self-attention

  • Feed-Forward Network (FFN)

  • Residual connections + LayerNorm

Every word attends to all other words (left + right).

Bidirectional self-attention

Bidirectional self-attention is a mechanism where each token in a sequence can attend to all other tokens on both its left and right, allowing the model to capture full context for understanding each word.

Example:

  1. Input: Sequence of token embeddings, e.g.

"I love transformers" → [x₁, x₂, x₃]

  1. Create Queries (Q), Keys (K), Values (V)

Q = X W_Q, K = X W_K, V = X W_V

  1. Compute attention scores:

score_{i,j} = (Q_i · K_j) / sqrt(d_k)

Every token compares itself with all tokens in the sequence

  1. Softmax to get attention weights:

α_{i,j} = softmax(score_{i,j})

  1. Weighted sum of values:

z_i = Σ_j α_{i,j} V_j

Each token now contains information from all tokens (both left and right)

Why bidirectional?

Some words need context from both sides:

"bank" in "I went to the bank to deposit money"

  • Left context: "I went to the"

  • Right context: "to deposit money"

→ Only bidirectional attention captures the full meaning.

Pretraining objectives of BERT

Masked Language Modeling (MLM)

  • Random words are masked: I love [MASK]

  • Model predicts: transformers

Learns bidirectional context

Output of BERT

  • Token-level embeddings → NER, POS tagging

  • [CLS] embedding → classification tasks

12.12.2GPT architecture

GPT (Generative Pre-trained Transformer) is a Transformer decoder-based model designed to generate language by predicting the next token using only past context. Used for:

  • Text generation

  • Chatbots

  • Story writing

  • Code generation

  • Summarization

GPT → Generate text → Decoder only → Uses causal masking → Maintains generation realism→ Autoregressive text generation

Input representation

GPT input = Token Embedding + Positional Embedding

Example: I love No segment embeddings, no [CLS].

Decoder layers (core of GPT)

GPT consists of stacked Transformer decoder layers. Each decoder layer has:

  • Masked self-attention

  • Feed-Forward Network (FFN)

  • Residual connections + LayerNorm

Masked self-attention (causal attention)

A token can only attend to past tokens, never future tokens.

Example: "I love transformers"

While predicting "transformers", GPT sees: "I", "love" but not "transformers" itself.

Pre-training objective of GPT

Next-Token Prediction: Model learns:

P(wordₜ | word₁, word₂, ..., wordₜ₋₁)

Example:

I love → transformers

Enables fluent text generation

Output of GPT

  • Probability distribution over vocabulary

  • Used to generate text token by token

Code to finetune GPT

# ============================================
# GPT-2 FINE-TUNING
# ============================================
# Install if needed:
# pip install transformers datasets torch accelerate
import torch
from datasets import load_dataset
from transformers import (
GPT2TokenizerFast,
GPT2LMHeadModel,
Trainer,
TrainingArguments,
DataCollatorForLanguageModeling,
pipeline
)
# --------------------------------------------
# 1. LOAD DATASET (CSV)
# CSV format:
# text
# Hello world
# GPT is powerful
# --------------------------------------------
dataset = load_dataset(
"csv",
data_files={"train": "train.csv"}
)
# --------------------------------------------
# 2. LOAD TOKENIZER
# --------------------------------------------
tokenizer = GPT2TokenizerFast.from_pretrained("gpt2")
tokenizer.pad_token = tokenizer.eos_token # GPT needs this
# --------------------------------------------
# 3. TOKENIZATION
# --------------------------------------------
def tokenize(batch):
return tokenizer(
batch["text"],
truncation=True,
padding="max_length",
max_length=128
)
dataset = dataset.map(tokenize, batched=True, remove_columns=["text"])
dataset.set_format("torch")
# --------------------------------------------
# 4. LOAD GPT MODEL
# --------------------------------------------
model = GPT2LMHeadModel.from_pretrained("gpt2")
model.resize_token_embeddings(len(tokenizer))
# --------------------------------------------
# 5. DATA COLLATOR (for LM)
# --------------------------------------------
data_collator = DataCollatorForLanguageModeling(
tokenizer=tokenizer,
mlm=False # IMPORTANT: GPT is causal LM
)
# --------------------------------------------
# 6. TRAINING CONFIG
# --------------------------------------------
training_args = TrainingArguments(
output_dir="./gpt_results",
overwrite_output_dir=True,
num_train_epochs=3,
per_device_train_batch_size=4,
learning_rate=5e-5,
weight_decay=0.01,
save_strategy="epoch",
logging_steps=50,
fp16=torch.cuda.is_available()
)
# --------------------------------------------
# 7. TRAINER
# --------------------------------------------
trainer = Trainer(
model=model,
args=training_args,
train_dataset=dataset["train"],
data_collator=data_collator,
tokenizer=tokenizer
)
# --------------------------------------------
# 8. TRAIN
# --------------------------------------------
trainer.train()
# --------------------------------------------
# 9. SAVE MODEL
# --------------------------------------------
model.save_pretrained("gpt_finetuned")
tokenizer.save_pretrained("gpt_finetuned")
print("GPT model fine-tuned and saved!")
# --------------------------------------------
# 10. LOAD & GENERATE TEXT
# --------------------------------------------
generator = pipeline(
"text-generation",
model="gpt_finetuned",
tokenizer="gpt_finetuned"
)
output = generator(
"Deep learning is",
max_length=50,
num_return_sequences=1
)
print(output[0]["generated_text"])
