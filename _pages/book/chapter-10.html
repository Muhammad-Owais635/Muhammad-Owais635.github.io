10.1Why LSTM Was Invented

RNNs suffer from several major limitations. During training, they often face the vanishing gradient problem, where gradients become very small and prevent the network from learning effectively from earlier time steps. As a result, RNNs have short-term memory, meaning they quickly forget older information and cannot learn long-term dependencies in sequences. To overcome these problems, LSTMs introduce a controlled memory flow using gates, which allow the network to decide what information to remember, update, or forget over long sequences.

10.2LSTM Architecture

Remember what matters. Forget what doesn’t. LSTM maintains the Cell state (long-term memory) and the Hidden state (short-term output)

Input xt​

  • The current word or input at time step t

  • Example: a word in a sentence

Previous Hidden State ht−1​

  • Short-term memory from the previous time step

  • Carries recent context

Previous Cell State Ct−1​(Top Horizontal Line)

  • Long-term memory

  • Flows almost straight across the cell

  • This is why LSTM remembers information for a long time

Forget Gate ft​

Purpose: Decide what to forget from old memory

ft​=σ(Wf​[ht−1​,xt​])

  • Output between 0 and 1

  • 0 → forget

  • 1 → keep

Removes useless old information

Input Gate it​

Purpose: Decide what new information to store

it​=σ(Wi​[ht−1​,xt​])

Candidate Memory Ct​

Purpose: Create new candidate content to add

Ct​=tanh(Wc​[ht−1​,xt​])

  • Values between −1 and 1

Update Cell State Ct​

Ct​=ft​⊙Ct−1​+it​⊙Ct​

Combines:

  • Old memory (after forgetting)

  • New important information

Output Gate ot​

Purpose: Decide what part of memory to show as output

ot​=σ(Wo​[ht−1​,xt​])

Hidden State / Output ht​

ht​=ot​⊙tanh(Ct​)

  • This is the output of the LSTM

  • Passed to next time step

10.4Bidirectional LSTM

A Bidirectional LSTM (BiLSTM) is a type of Recurrent Neural Network (RNN) that processes a sequence in both forward and backward directions using two separate LSTM layers.

  • Forward LSTM: reads the sequence from past → future

  • Backward LSTM: reads the sequence from future → past

The outputs of both directions are then combined (concatenated or summed) at each time step. This allows the model to use past and future context simultaneously, which is especially useful in sequence understanding tasks.

Why use BiLSTM?

Standard LSTMs only use past information. BiLSTMs improve performance when future context matters, such as, Natural Language Processing (POS tagging, NER, sentiment analysis), Speech recognition, Handwriting recognition and Time-series labeling (not forecasting).

Conceptual Example

Sentence: “I went to the bank to deposit money”

To understand the word “bank”, the model benefits from:

  • Past context: “went to the”

  • Future context: “deposit money”

10.5LSTM in Keras (Example)

import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Embedding
model = Sequential([
Embedding(input_dim=5000, output_dim=64, input_length=20),
LSTM(units=50),
Dense(1, activation='sigmoid')
])
model.compile(
optimizer='adam', loss='binary_crossentropy', metrics=['accuracy']
)
model.summary()

Parameters explained

  • input_dim = 5000
    → Vocabulary size (maximum number of unique words)

  • output_dim = 64
    → Embedding dimension (each word becomes a 64-dim vector)

  • input_length = 20
    → Length of each input sequence (20 words per sentence)
