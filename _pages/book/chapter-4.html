Loss Functions

7 min read 7 sections Draft

4.1What Is a Loss Function?

A loss function measures how wrong a model’s prediction is compared to the true label. Without a loss function, a neural network has no clear measure of how good or bad its predictions are, so the model does not know what needs to be improved. Since gradient descent relies on the loss value to determine the direction and magnitude of parameter updates, it has no direction to follow in the absence of a loss function. As a result, the network cannot adjust its weights meaningfully, making learning impossible. Therefore, the loss function acts as the objective that the network tries to minimize during training, guiding the entire learning process. Optimization tries to minimize this loss.

Term Meaning
Loss Error for one data sample
Cost Average loss over entire dataset

The loss and cost functions are closely related but differ in scope. Loss refers to the error calculated for a single training example, measuring how far the model’s prediction is from the true value for that one data point. In contrast, cost represents the average (or total) loss over the entire training dataset or over a batch of examples. In simple terms, loss is a point-wise measure of error, while cost summarizes the overall performance of the model across many samples. During training, optimization algorithms such as gradient descent aim to minimize the cost, which is derived from individual losses.

4.2Mean Squared Error (MSE)

Mean Squared Error (MSE) is a commonly used loss function that measures the average of the squared differences between the predicted values and the actual target values. By squaring the errors, MSE gives more importance to larger mistakes, making it sensitive to outliers. It provides a smooth and continuous error surface, which is useful for optimization using gradient-based methods.

MSE=n1​i=1∑n​(yi​−y​i​)2

MSE is used mainly in regression problems where the goal is to predict continuous numerical values, such as house prices, temperature, or sales forecasting. It works well when errors are expected to be normally distributed and when large errors should be penalized more heavily.

However, MSE should not be used when the dataset contains significant outliers, as squaring the error can cause these outliers to dominate the loss and negatively affect model performance. It is also not suitable for classification problems, where loss functions like cross-entropy are more appropriate, and in cases where robustness to extreme errors is required (where MAE may be a better choice).

4.3Mean Absolute Error (MAE)

Mean Absolute Error (MAE) is a loss function that measures the average of the absolute differences between the predicted values and the actual target values. Unlike MSE, it treats all errors equally without squaring them, making it less sensitive to outliers. MAE provides a clear interpretation of error in the same units as the target variable.

MAE=n1​i=1∑n​∣yi​−y​i​∣

MAE is used mainly in regression problems where robustness to outliers is important, such as predicting prices in noisy datasets or when extreme errors should not dominate the learning process. It is especially useful when a linear penalty on errors is preferred.

However, MAE should not be used when smooth gradients are required for optimization, because the absolute value function is not differentiable at zero and has a constant gradient elsewhere, which can slow down convergence. It is also not ideal when large errors should be penalized more strongly, in which case MSE is usually a better choice.

4.4Binary Cross-Entropy Loss (Log Loss)

Binary Cross-Entropy Loss, also known as Log Loss, is a loss function used to measure the performance of a classification model whose output is a probability between 0 and 1. It quantifies how well the predicted probabilities match the actual binary labels, heavily penalizing confident but incorrect predictions.

Formula

BCE=−n1​i=1∑n​[yi​log(y​i​)+(1−yi​)log(1−y​i​)]

Binary Cross-Entropy Loss is used mainly in binary classification problems, such as spam detection, disease diagnosis, or yes/no decision tasks, especially when the model’s output layer uses a sigmoid activation function. It provides strong gradients that help the model learn accurate probability estimates.

However, Binary Cross-Entropy Loss should not be used for multi-class classification problems, where categorical cross-entropy or softmax-based losses are more appropriate. It is also not suitable when model outputs are not probabilities or when labels are continuous values, as it is designed specifically for binary outcomes.

4.5Categorical Cross-Entropy

Categorical Cross-Entropy is a loss function used to measure the difference between the true class distribution and the predicted probability distribution in multi-class classification problems. It evaluates how well the model assigns high probability to the correct class while penalizing incorrect class predictions.

CCE=−n1​i=1∑n​j=1∑C​yij​log(y​ij​)

Categorical Cross-Entropy is used mainly in multi-class classification tasks where each sample belongs to exactly one class, such as image recognition or text classification with multiple categories. It is typically used with a softmax activation function in the output layer and requires the true labels to be one-hot encoded.

However, Categorical Cross-Entropy should not be used for binary classification problems, where binary cross-entropy is simpler and more appropriate. It is also not suitable when class labels are not one-hot encoded (in such cases, sparse categorical cross-entropy is preferred) or for regression tasks involving continuous target values.

4.6Sparse Categorical Cross-Entropy

Sparse Categorical Cross-Entropy is a loss function used for multi-class classification problems where the true class labels are provided as integer class indices instead of one-hot encoded vectors. It measures the difference between the true class and the predicted probability distribution over all classes.

SCCE=−n1​i=1∑n​log(y​i, yi​​)

Sparse Categorical Cross-Entropy is used mainly in multi-class classification tasks when there are many classes and using one-hot encoding would be inefficient or memory-intensive, such as large-scale image or text classification problems. It is commonly used with a softmax activation function in the output layer and produces the same result as categorical cross-entropy, but with simpler label representation.

However, Sparse Categorical Cross-Entropy should not be used for binary classification problems, where binary cross-entropy is more appropriate. It is also not suitable when labels are already one-hot encoded or for regression tasks involving continuous output values.

4.7Hinge Loss (Brief)

Hinge Loss is a loss function mainly used for binary classification, especially with Support Vector Machines (SVMs). It focuses on maximizing the margin between classes by penalizing predictions that are correct but not confident enough, as well as incorrect predictions.

Hinge Loss=max(0,1−y⋅y​)

(where y∈{−1,+1})

Hinge Loss is used when training SVMs and margin-based classifiers, as it encourages clear separation between classes. However, it is not suitable for probabilistic outputs, regression tasks, or models that use sigmoid or softmax activations, since it does not produce probability-based learning.
