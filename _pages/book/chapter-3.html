Activation Functions

6 min read 2 sections Draft

3.1Why Activation Functions Are Needed

Each neuron in NN applies an activation function. Activation functions are needed because, without them, a neural network becomes linear, meaning the output is just a weighted sum of inputs and stacking multiple layers does not increase learning power—the whole network behaves like a single layer. Linear means the relationship between input and output is a straight-line relationship that cannot model curves or complex patterns. With activation functions, non-linearity is introduced, allowing the network to learn complex, curved, and real-world patterns such as images, speech, and language.

3.2Type of Activation Function

Linear Activation Function

A linear activation function is an activation function in which the output of a neuron is directly proportional to its input. It does not introduce any non-linearity into the model; instead, it simply passes the weighted sum of inputs through unchanged (or scaled). Because of this, a neural network using only linear activation functions behaves like a single-layer model, no matter how many layers it has.

f(x)=ax+b

(Usually a=1and b=0, so f(x)=x)

A linear activation function is used mainly in the output layer of regression models, where the task is to predict continuous values such as price, temperature, or weight. It is suitable when the relationship between input and output is approximately linear and there is no need to limit the output range.

Sigmoid Activation Function

A sigmoid activation function is a non-linear activation function that maps input values into a fixed range between 0 and 1. It is especially useful for modeling probabilities because its output can be interpreted as the likelihood of a particular class. The sigmoid function introduces non-linearity into the neural network, allowing it to learn complex patterns.

f(x)=1+e−x1​

The sigmoid activation function is used mainly in the output layer of binary classification models, where the output represents the probability of belonging to a positive class (0 or 1). It is also helpful when a smooth gradient is required and outputs need to be bounded between 0 and 1.

However, the sigmoid function should not be used in hidden layers of deep neural networks in most modern applications. This is because it suffers from the vanishing gradient problem, where gradients become very small for large positive or negative input values, slowing down or stopping learning. It is also not suitable for multi-class classification (more than two classes), where functions like softmax are preferred.

Hyperbolic Tangent (Tanh)

The Hyperbolic Tangent (tanh) activation function is a non-linear activation function that maps input values into a range between −1 and +1. It is similar to the sigmoid function but is zero-centered, which helps neural networks converge faster during training by balancing positive and negative activations.

f(x)=tanh(x)=ex+e−xex−e−x​

The tanh activation function is used mainly in hidden layers of neural networks, especially when the data is centered around zero. Because its outputs include both negative and positive values, it often performs better than sigmoid in hidden layers and helps with gradient-based optimization in shallow to moderately deep networks.

However, the tanh function should not be used in very deep networks in most modern applications. Like the sigmoid function, it suffers from the vanishing gradient problem for very large or very small input values. It is also not suitable for output layers where probabilities are required (use sigmoid or softmax instead) or for regression tasks with unbounded outputs.

ReLU (Rectified Linear Unit)

The ReLU (Rectified Linear Unit) activation function is a non-linear activation function that outputs zero for negative input values and outputs the input itself for positive values. It is one of the most widely used activation functions in modern neural networks because it is simple, computationally efficient, and helps reduce the vanishing gradient problem.

f(x)=max(0,x)

The ReLU activation function is used mainly in the hidden layers of deep neural networks, especially in convolutional neural networks (CNNs) and deep feedforward networks. It allows models to learn complex patterns efficiently and speeds up training due to its linear behavior for positive values.

However, ReLU should not be used when many neurons may receive negative inputs all the time, as this can lead to the dying ReLU problem, where neurons stop learning because their output becomes permanently zero. It is also not ideal for output layers in regression tasks that require negative values or for probability outputs, where linear, sigmoid, or softmax functions are more appropriate.

Leaky ReLU

The Leaky ReLU activation function is a variant of the ReLU function designed to solve the dying ReLU problem. Instead of outputting zero for all negative input values, Leaky ReLU allows a small, non-zero gradient when the input is negative. This helps neurons continue learning even if they receive negative inputs.

f(x)={x,αx,​if x>0if x≤0​ 
(where αis a small constant, commonly 0.01)

Leaky ReLU is used mainly in the hidden layers of deep neural networks when standard ReLU causes many neurons to become inactive. By allowing a small slope for negative values, it improves gradient flow and makes training more stable, especially in deep or complex models.

However, Leaky ReLU should not be used when strict sparsity (many exact zeros) is desired, since it always produces some output for negative inputs. It may also be less effective if the choice of αis not appropriate, and in some cases other variants like Parametric ReLU (PReLU) or ELU may perform better.

Softmax Activation Function

The Softmax activation function is a non-linear activation function that converts a vector of real-valued inputs into a probability distribution. Each output value lies between 0 and 1, and the sum of all output values equals 1. This makes Softmax especially useful for multi-class classification problems, where the model must choose one class among many.

f(xi​)=∑j=1n​exj​exi​​

The Softmax activation function is used mainly in the output layer of multi-class classification neural networks, such as image classification or text classification tasks with more than two classes. It allows the network’s outputs to be interpreted as class probabilities, making it easy to select the most likely class.

However, Softmax should not be used in hidden layers because it forces outputs to compete with each other and can slow down learning. It is also not suitable for binary classification (where sigmoid is simpler and more efficient) or regression tasks, where continuous unbounded outputs are required.
