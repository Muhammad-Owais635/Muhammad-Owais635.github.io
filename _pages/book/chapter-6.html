Chapter 06

The Training Process: Epochs, Batches and Learning Rate

3 min read 6 sections Draft

6.1 Parameters are the values that a model learns automatically during training from the data. They directly affect the model’s predictions and are updated using backpropagation and gradient descent.
Example: weights and biases (w,b) in a neural network.

6.2 Hyperparameters are the values that are set before training and control how the learning process happens. They are not learned from data and must be chosen or tuned by the user.
Example: learning rate (η), number of hidden layers, number of neurons, batch size, and number of epochs.

6.1What Is an Epoch?

An epoch means, the model has seen every training sample once

Example: Dataset size = 1,000 samples

Epoch What Happens
1 Model sees all 1,000 samples
10 Model sees 10,000 samples
100 Model sees 100,000 samples

6.2What Is Batch Size?

Batch size = number of samples used before one weight update

Example: When the dataset contains 1,000 samples and the batch size is 100, the data is divided into 10 mini-batches. During training, the model processes each batch separately, and after completing the forward and backward pass for one batch, it updates the weights once. This means Batch 1 leads to one update, Batch 2 leads to another update, and this continues until Batch 10, resulting in 10 weight updates in one epoch.

Epoch vs Batch Size

Batch Size Updates per Epoch
1 (SGD) 1000
32 ~32
128 ~8
1000 (Batch GD) 1

6.3What Is an Iteration?

An iteration refers to one complete weight update of the model during training. In other words, every time the model processes a batch of data and updates its weights, one iteration is completed.

Example:
If a dataset has 1,000 samples and the batch size is 100, the data is divided into 10 batches. Each batch causes one weight update, so 1 epoch contains 10 iterations.

6.4Learning Rate

The learning rate is a small value that controls how much the model’s weights are updated during training; it decides the step size in gradient descent. For example, common learning rate values are 0.1 (fast but risky), 0.01 (most commonly used), and 0.001 (slow but stable).

Optimizer Common LR
SGD 0.01
Adam 0.001
RMSprop 0.001

6.5Bias and Variance

Bias refers to the error caused by a model being too simple and making strong assumptions about the data. A high-bias model cannot capture complex patterns, so it consistently makes similar mistakes across different datasets.

Variance refers to the error caused by a model being too complex and highly sensitive to the training data. A high-variance model learns noise and small fluctuations in the data, which leads to large changes in predictions when the input data changes.

6.6Overfitting and Underfitting

Underfitting occurs when a model is too simple to capture the underlying patterns in the data. It performs poorly on both the training data and the test data because it fails to learn important relationships. Underfitting is linked to high bias and low variance.

Example: using a straight line to fit highly curved data or training for too few epochs.

Overfitting occurs when a model learns the training data too well, including noise and random fluctuations. As a result, it performs very well on training data but poorly on unseen test data.
Example: a very complex model trained for too many epochs that memorizes the training samples instead of learning general patterns. Overfitting is linked to low bias and high variance.
