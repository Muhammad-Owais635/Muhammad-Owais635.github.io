Chapter 05

Gradient Descent and Optimization

12 min read 7 sections Draft

Optimizers are algorithms used to update a model’s parameters (weights and biases) in order to minimize the loss function. They decide how much and in which direction the parameters should change using gradients during training, helping the model learn efficiently and converge faster.

5.1What Is Gradient Descent?

Gradient Descent is an optimization algorithm used to minimize the loss function by iteratively updating model parameters (weights and bias). Gradient descent answers one question:
“In which direction should I change the weights to reduce loss?”. Gradient descent provides a systematic way to learn from errors

5.2Intuition: Hill Descent Analogy

Imagine you are standing on a hill in fog 🌫️ and want to reach the lowest point (minimum loss).

  • Look at the slope

  • Take a small step downhill

  • Repeat until reaching the bottom

5.3Mathematical Idea Behind Gradient Descent

In a neural network, parameters are the values the model learns during training, mainly the weights (w) and biases (b). These parameters control how input data is transformed into output predictions. To improve the model, we need a way to measure how changing these parameters affects the error, which is done using the loss function.

The gradient is the derivative of the loss with respect to the model parameters. It tells us how much and in which direction the loss changes when a parameter changes. The gradient always points in the direction of the steepest increase in loss. Since our goal is to reduce the loss, we update the parameters in the opposite direction of the gradient. This idea is the core of gradient descent.

The weight update rule shows how parameters are adjusted during training. Each weight and bias is updated by subtracting a small portion of the gradient from its current value. The size of this step is controlled by the learning rate (η), which determines how fast or slow the model learns. A small learning rate leads to slow learning, while a very large one can cause the model to overshoot the minimum.

w=w−η∂w∂L​b=b−η∂b∂L​

Here, ηis the learning rate, and ∂w∂L​and ∂b∂L​are the gradients, representing how sensitive the loss Lis to changes in the weight and bias. By repeatedly applying these updates, the model gradually learns the parameter values that minimize the loss.

The learning rate is a small value that controls how much the model’s weights are updated during training; it decides the step size in gradient descent. For example, common learning rate values are 0.1 (fast but risky), 0.01 (most commonly used), and 0.001 (slow but stable).

5.4Types of Gradient Descent

Batch Gradient Descent

Batch Gradient Descent is an optimization technique in which the model updates its parameters using the entire training dataset. For each update, the loss is calculated for all training examples, the gradients are averaged, and then the weights and biases are updated. This results in a smooth and stable path toward the minimum loss but requires high computation time and memory.

w=w−ηn1​i=1∑n​∂w∂Li​​b=b−ηn1​i=1∑n​∂b∂Li​​

Batch Gradient Descent is used when the dataset is small and can fit into memory, as it provides consistent and stable convergence. However, it is not suitable for very large datasets because it is slow, computationally expensive, and updates the parameters only after processing the entire dataset.

Stochastic Gradient Descent (SGD)

Stochastic Gradient Descent (SGD) is an optimization algorithm in which the model updates its parameters after every single training example. Instead of using the entire dataset, SGD computes the gradient using one randomly selected data point at a time. This enables faster learning and allows the model to start improving immediately; however, the updates are noisy and less stable.

w=w−η∂w∂Li​​b=b−η∂b∂Li​​

Here, the gradient is calculated using only one training sample i. SGD is used for very large datasets and online learning because it is computationally efficient and can escape local minima. However, it is not ideal when smooth and stable convergence is required, as the frequent updates can cause fluctuations around the minimum loss.

Mini-Batch Gradient Descent (Most Used)

Mini-Batch Gradient Descent is an optimization algorithm that updates model parameters using a small subset (mini-batch) of the training data instead of the entire dataset or a single data point. It combines the advantages of Batch Gradient Descent (stable updates) and Stochastic Gradient Descent (fast updates), which is why it is the most commonly used method in practice.

w=w−ηm1​i=1∑m​∂w∂Li​​b=b−ηm1​i=1∑m​∂b∂Li​​

Here, mis the mini-batch size (commonly 32, 64, or 128). Mini-Batch Gradient Descent is used in most deep learning models because it is memory efficient, computationally fast, and provides stable yet frequent updates. However, choosing an inappropriate batch size can affect performance—very small batches add noise, while very large batches behave like slow batch gradient descent.

5.5Backpropagation (How Neural Networks Learn)

Backpropagation is an algorithm used to compute gradients efficiently for all weights and biases in a neural network using the chain rule of calculus.

Backpropagation answers:

“How much did each weight contribute to the final error?”

5.6Other Types of Optimizers

Vanilla Gradient Descent

Vanilla Gradient Descent is the basic optimization algorithm that updates model parameters by moving them in the opposite direction of the gradient of the loss function. It uses a fixed learning rate and applies the standard gradient descent update rule without any enhancements like momentum, adaptive learning rates, or variance correction.

w=w−η∇L

It is simple and easy to understand, but it can be slow, sensitive to the choice of learning rate, and may get stuck in local minima or oscillate in narrow valleys.

SGD with Momentum

SGD with Momentum is an improved version of Stochastic Gradient Descent that helps accelerate learning and reduce oscillations. It works by adding a fraction of the previous update to the current update, allowing the optimizer to build speed in directions with consistent gradients.

vt​=γvt−1​+η∇Lw=w−vt​

Here, vt​is the velocity, γis the momentum coefficient (commonly 0.9), and ηis the learning rate. Momentum helps the optimizer converge faster and smoother, especially in deep networks.

Nesterov Accelerated Gradient (NAG)

Nesterov Accelerated Gradient (NAG) is an improved version of SGD with momentum that looks ahead before updating the parameters. Instead of computing the gradient at the current position, it first moves in the direction of the previous momentum and then calculates the gradient, allowing more accurate and faster updates.

vt​=γvt−1​+η∇L(w−γvt−1​)w=w−vt​

Here, γis the momentum coefficient and ηis the learning rate. NAG helps reduce overshooting and provides better convergence compared to standard momentum-based SGD.

Adagrad (Adaptive Gradient)

Adagrad (Adaptive Gradient) is an optimizer that adapts the learning rate for each parameter individually based on how frequently it is updated. Parameters that receive large gradients get smaller learning rates, while parameters with small or infrequent gradients get larger learning rates. This makes Adagrad especially useful for sparse data.

Gt​=Gt−1​+(∇L)2w=w−Gt​​+ϵη​∇L

Here, Gt​is the sum of squared past gradients, ηis the learning rate, and ϵis a small constant to avoid division by zero. Although Adagrad works well for sparse features, its main drawback is that the learning rate keeps decreasing and can become too small over time, slowing or stopping learning.

RMSprop

RMSprop (Root Mean Square Propagation) is an adaptive learning rate optimizer designed to fix Adagrad’s problem of continuously shrinking learning rates. Instead of accumulating all past squared gradients, RMSprop uses an exponentially decaying average, allowing the model to keep learning even after many updates.

E[g2]t​=βE[g2]t−1​+(1−β)(∇L)2w=w−E[g2]t​​+ϵη​∇L

Here, β(commonly 0.9) controls the decay rate, ηis the learning rate, and ϵis a small constant for numerical stability. RMSprop works well for non-stationary problems and is widely used in deep learning, especially with recurrent neural networks.

Adam (Adaptive Moment Estimation)

Adam (Adaptive Moment Estimation) is one of the most widely used optimizers in deep learning. It combines the benefits of Momentum and RMSprop by maintaining exponentially decaying averages of both the gradients (first moment) and the squared gradients (second moment), leading to fast and stable convergence.

mt​=β1​mt−1​+(1−β1​)∇Lvt​=β2​vt−1​+(1−β2​)(∇L)2

Bias correction

mt​=1−β1t​mt​​,vt​=1−β2t​vt​​

Parameter update

w=w−vt​​+ϵη​mt​

Here, ηis the learning rate, β1​(≈0.9) controls momentum, β2​(≈0.999) controls RMSprop behavior, and ϵensures numerical stability. Adam is efficient, requires little tuning, and works well for large datasets and deep neural networks.
